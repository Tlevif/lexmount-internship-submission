# 计算机技术实习岗位聚合平台

## 1. 项目简介

企业实习岗位分散在不同招聘官网，页面结构、筛选方式和数据加载机制各不相同，查找与比较较为费时。

本项目汇集北京、上海、广州、深圳、杭州的计算机技术实习信息，支持按企业、城市和技术方向检索，查看岗位职责、任职要求、技术栈及官方来源。

## 2. 技术实现

- **Lexmount WebFetch：** 发现招聘入口，提取公开网页内容与岗位数据。
- **Lexmount Cloud Browser：** 完成动态页面渲染、交互筛选、分页与详情读取。
- **Python / FastAPI：** 清洗、去重和分类，提供检索与数据导出。
- **人工与 Codex：** 人工确定目标和筛选标准，Codex 辅助开发采集程序、检查数据质量并整理验证材料。

## 3. 项目成果

当前结果：3,095 条岗位、32 家企业、9 个技术大方向，110 项软件测试通过。

- **信息完整：** 当前收录岗位均有职责、任职要求与官方来源。
- **分级检索：** 大模型、开发等方向支持继续细分，便于按实际技术任务查找岗位。
- **结果可核验：** 完整数据、分类说明、云端截图与运行记录均可下载。

## 4. 技术问题与解决方案

- **动态页面：** 对无法直接读取正文的页面，使用 Cloud Browser 完成交互并提取岗位信息。
- **详情缺失或错位：** 重新读取官网内容，按实际栏目核对职责和要求，完成当前收录岗位的字段补全。
- **分类不准确：** 结合岗位名称、实际职责和技术要求分类，减少部门标签造成的误判。
- **分页与重复：** 按稳定岗位标识去重，保留原始采集记录用于复核。
